# Сборка русификатора

`build.php` в корне этого репозитория собирает пакет русского языка для OpenCart 4. Каркас расширения — каталог `ocn_language_russian.ocmod` рядом со скриптом. Фразы читаются из ветки `lang-v4` форка OpenCart через `git archive`: рабочая ветка форка при этом не переключается. Имя ветки задаёт `OPENCART_BRANCH`.

Готовый архив появляется в `dist/ocn_language_russian.ocmod.zip`. Каталоги `dist/` и `build/` в git не попадают.

## Запуск

Скрипт запускается из корня форка OpenCart или из этого каталога (в форке это `ocn/language`).

Без аргументов версия для `install.json` читается из константы `VERSION` в `upload/index.php` выбранной ветки:

```text
php ocn/language/build.php
php build.php
```

Версию можно передать позиционным аргументом или флагом:

```text
php build.php 4.1.0.4
php ocn/language/build.php --version=4.1.0.4
```

Нужен один позиционный аргумент — сама версия. Пустая строка и строка из пробелов не подставляются. Справка: `php build.php --help`.

## Копирование фраз в репозиторий

```text
php build.php 4.1.0.4 --copy
php ocn/language/build.php 4.1.0.4 --copy
```

`--copy` после сборки zip копирует свежие `ru-ru` из ветки `lang-v4` в `ocn_language_russian.ocmod/` так, как они лежат в архиве: `admin/language/ru-ru`, `catalog/language/ru-ru`, пути расширений — внутрь `language/ru-ru/extension/opencart`. Обновляются `install.json` (поле version) и `composer.json` (поле version, если оно есть). Коммит не создаётся. Zip остаётся в `dist/`.

Без `--copy` и без `--tag` рабочее дерево репозитория не меняется, собирается только zip.

## Тег

Тег не равен версии сам по себе. `--tag` подразумевает `--copy`: сначала копирование, затем коммит и аннотированный тег.

```text
php build.php 4.1.0.4 --tag=4.1.0.4
php ocn/language/build.php 4.1.0.4 --tag 4.1.0.4
```

Коммит и тег пишутся в этот репозиторий, не в форк OpenCart:

- в коммит входят скопированные файлы перевода, `ocn_language_russian.ocmod/install.json` и `composer.json`, если version изменился;
- zip не добавляется: `*.zip`, `dist/` и `build/` указаны в `.gitignore`, архив остаётся в `dist/`;
- сообщение коммита и аннотированного тега — номер версии, имя тега берётся из `--tag`.

Push скрипт не выполняет. Если рабочее дерево уже содержит посторонние правки, сборка с `--tag` останавливается и не перезаписывает их. Файл `.env` в коммит не попадает.

## Настройки

Скопируйте `.env.example` в `.env` и укажите пути этой машины:

- `OPENCART_REPO` — корень форка (родитель каталога `ocn`). Пустое значение — два уровня выше этого файла;
- `OPENCART_BRANCH` — ветка с фразами, по умолчанию `lang-v4`;
- `PACKAGE_DIR` — корень этого репозитория. Пустое значение — каталог скрипта.

Версия и тег в `.env` не задаются. Файл `.env` не коммитится.

Установка готового архива описана в `README.md`.
